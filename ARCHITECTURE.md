# Architecture

- Next.js App Router
- Server Components by default
- Evidence Ledger in src/data/servers.ts
- Publication gate in src/lib/evidence.ts
- SEO metadata via src/lib/seo.ts
- JSON-LD graph via src/lib/schema-graph.ts
- Sitemap and robots generated from the same source of truth
